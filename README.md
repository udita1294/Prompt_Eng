# Prompt Engineering 

This repository contains my hands-on practice and experiments while learning **Prompt Engineering** as part of my Generative AI journey. It includes examples of writing effective prompts, understanding prompt design techniques, and interacting with Large Language Models (LLMs) using the Groq API.

The goal of this repository is to document my learning process, explore prompt engineering concepts, and build a strong foundation for developing LLM-powered applications.

##  Example Learning

### Basic Prompt

```text
This is a user complaint, my laptop is not working. Classify this.
```

### Structured Prompt

* Define the role
* Specify the task
* Add constraints
* Specify output format
* Provide examples
* Include fallback behavior

This demonstrates how prompt structure can significantly improve the consistency and accuracy of LLM responses.
